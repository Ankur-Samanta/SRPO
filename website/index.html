02 / Why resets work

The useful learning signal lives in improvable states.

The paper studies resets through Conservative Policy Iteration (CPI), the policy-improvement framework underlying methods such as PPO and GRPO. The central question is simple: if we can afford to explore only a few points in a reasoning trace, which points should we choose?

Step 1 · Find where improvement is possible

Most visited states may have little useful signal.

A state is τ-improvable when the policy could take a different next action that is better by at least τ. If only one in ten visited states has that property, then pπ = 0.1. Those rare states dominate the possible improvement; sampling everywhere else spends rollout budget where the gain does not live.

Step 2 · Avoid signal dilution

Random sampling sees τpπ. Targeted sampling sees τ.

Random-reset CPI averages over every state it visits. Because an improvable state appears only with probability pπ, its guaranteed advantage is diluted from τ to τpπ. A credit-assignment oracle conditions directly on the improvable set, preserving the full signal.

Step 3 · Turn stronger signal into faster improvement

Conditioning changes both estimation and the update.

Estimation error falls with the square root of the sample count. Making the target signal 1/pπ larger therefore cuts the expensive rollout requirement by 1/pπ2. And because the policy changes only on the improvable set, CPI can take a 1/pπ larger conservative step.

The realistic case

What if the localizer is imperfect?

A practical localizer selects an approximate set of reset states, 𝒮, rather than the true improvable set 𝒢. Its mistakes affect learning in two distinct ways.

β

False discoveries dilute the signal.

If a fraction β of selected states are not actually improvable, the guaranteed signal falls from τ to (1−β)τ.

γ

Misses reduce where the update applies.

Recall γ controls how many truly improvable states are retained. Missing one does not corrupt the signal; it reduces the mass of useful updates.

Approximate-localizer guarantee improvement ≥ (1−β)2 τ2 pν / 16HRmax

Perfect localization is not required—the benefit degrades smoothly with precision and recall.

Theory → practice

The oracle is an idealization. Self-localization is the implementation.

The theoretical oracle answers, “does this state admit a significantly better action?” In SRPO, the model approximates that oracle by identifying the first erroneous thought in its own failed trace. The clean prefix before that error is a state from which a better continuation may still recover the answer. It is an imperfect proxy—but the experiments show it is effective.

03 / The method

Reset. Resample. Reassign credit.

SRPO turns the model into its own credit-assignment oracle. After a failed rollout, the policy identifies its first erroneous thought. We keep the clean prefix, sample new suffixes from that shared state, and optimize their relative outcomes.

  1. 01
    Roll out

    Generate an initial thought-by-thought solution.

  2. 02
    Localize

    Find the first erroneous reasoning step.

  3. 03
    Reset

    Return to the clean, improvable prefix.

  4. 04
    Resample

    Compare suffixes and update only what follows.

Prefix masking removes the learning signal from the shared history. Credit is focused on the suffix—the region where sampled decisions actually differ.

05 / Sampling design

A controlled comparison under the same rollout budget.

SRPO and RRPO split eight rollouts into a fresh base group and a reset group. Reset suffixes share the same history, making outcome differences informative about the decisions after the chosen state.

The takeaway

Better reasoning does not require rewarding every token more carefully. It requires revisiting the state where a better decision was possible.
